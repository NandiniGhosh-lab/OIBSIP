# Personal Portfolio Website

A responsive personal portfolio website showcasing skills, projects, and contact information.

## Features

✅ Fixed/Sticky Navigation Bar - Easy navigation across sections
✅ Hero Section - Professional profile with call-to-action button
✅ About Me Section - Brief introduction and background
✅ Skills Section - Grid display of technical skills
✅ Projects Section - Showcase of 3 project examples
✅ Contact Section - Email and social media links
✅ Smooth Scrolling - Navigation links scroll smoothly
✅ Fully Responsive - Works on desktop, tablet, and mobile
✅ Clean Design - Consistent colour palette and typography

## Technologies Used

- HTML5 - Page structure
- CSS3 - Styling and layout
- JavaScript - Smooth scrolling functionality
- Google Fonts - Custom typography

## How to Use

1. Open index.html in your web browser
2. Click on navigation links to scroll to sections
3. Edit your name, skills, and projects as needed

## Responsive Design

The site works on all screen sizes:
- Desktop (1024px and above)
- Tablet (768px - 1023px)
- Mobile (below 768px)
